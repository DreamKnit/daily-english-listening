# 🎧 每日英语听力 (Daily English Listening)

基于 Flutter 开发的轻量级英语精听练习安卓应用，由 [@DreamKnit](https://github.com/DreamKnit) 维护。

## ✨ 核心功能 (v0.1.0 MVP)
- **双语时间轴同步字幕**：音频播放时自动高亮当前句子，支持点击任意行跳转复读。
- **即点即查与生词本**：直接点击英文字幕中的任意单词，底部弹出音标与释义卡片，支持一键加入本地生词本。
- **精听辅助控制**：支持 `0.8x` ~ `2.0x` 倍速调节、单句无限循环精听、`中英 / 纯英 / 纯中` 视图一键切换。
- **GitHub Actions 云端自动构建**：每次提交代码或发布标签，云端自动编译 Android Release APK 并发布至 GitHub Releases。

## 📥 下载安装包 (APK)
请直接前往本仓库右侧的 **[Releases 页面](https://github.com/DreamKnit/daily-english-listening/releases)** 下载最新版本的 `app-release.apk` 安装到安卓手机。
